# Data generation spec (database phase 6)

Everything generated here is **fictional** and labelled so: `real=false`, `club_type=FICTIONAL`, `player_type=GENERATED`, ids `fic_*` / `gen_*`. It lives in its own folder (`data/packs/real_2025/fictional/`), apart from the real data.

## What is generated
- **Fictional third divisions** in England (League One), Spain (Primera Federación), Germany (3. Liga), Italy (Serie C), France (National): 20 clubs each = 100 clubs and 2,800 players (28 per club). The league names are the real division names; the clubs in them are not real.
- Together with the real pack: **298 clubs, 8,013 players** (target 250-350 clubs, 8,000-12,000 players).
- Pyramid: each league now has 3 tiers; tier 2 relegates 3 and tier 3 promotes 3 (no play-off), so all division sizes stay constant. `LeagueDef` validation and `LeaguePyramid` are unchanged.

## Determinism
`world seed` (`data/generation/config.json`, 20251112) -> per club `RandomNumberGenerator` seeded with `hash([seed, country code, tier, index])`. The same seed and the same real data always give byte-identical files: the test suite regenerates everything in memory and requires every shipped club file and the manifest to match; running `tools/generate_world.tscn` twice produces no diff. A different seed gives a different world; the number of clubs per country is configurable (`per_country`).
Nothing is generated when a screen opens; generated records are ordinary pack files, saved with the game like any other club.

## Clubs (`ClubGenerator`, `WorldGenerator`)
- Country-aware invented places (syllable lists) + club-name style per country (England "X Rovers/Town/...", Spain "CD/UD/Real X", Germany "SV/FC/TSV X", Italy "AC/US/Pro X", France "FC/AS/Stade X").
- Names, places, 3-letter codes and ids are unique, and no club name equals or nearly equals (<= 1 letter) a real club.
- Reputation 36-54 (tier 3), budget 1.0-2.1 M, wage budget from the squad's wages, stadium name/capacity/level, founding year 1885-1995, city, 2 rivals inside the division, colours from a neutral palette (kits then go through the phase 5 kit repair).
- Crests: generated by the phase 4 generator, always after all other clubs so existing crests never change.

## Players (`ClubGenerator.generate_squad`)
28 players: 3 goalkeepers, 9 defenders, 8 midfielders, 4 wingers/attackers... (fixed layout, shirt numbers 1-28), ages 17-36 (25 % 17-21, 45 % 22-27, 25 % 28-33, 5 % 34-36), attributes from the club's reputation + position bias (shared with the youth generator), potential >= overall with more room for the young, ~80 % of the club's nationality and the rest from the other four countries, names always from the player's own nationality. Measured average team rating by tier: 78.2 / 66.4 / 58.6 (the ladder holds).

## Names (`NameBank`, `NameIndex`)
60-125 given names and 58-125 surnames per country (3,800-9,400 combinations). `NameIndex` normalises (case, accents, hyphens) and rejects an exact duplicate or a name one letter apart from any name already in the world, real players included; the checks are bucketed by first letter so thousands of names index in seconds. The youth generator now uses the same pools for the five countries (`YouthGenerator.pool_for`).
Limit: random combinations of common names can coincide with a real person outside the loaded data; this is by chance and the players are fictional.

## Youth
Academies of fictional clubs work like any other: prospects get names and nationality of the club's country (`yth_` ids, YOUTH type), deterministic appearance, and keep identity and appearance on promotion (tested).

## Regenerating
`godot --headless --path . res://tools/generate_world.tscn -- [seed] [per_country]`, then `tools/generate_crests.tscn`. Re-run both after rebuilding the real pack with `tools/import_real` (the importer rewrites the league files).

## Tests
`tests/db_generation_validation.tscn` (60 checks): name index and bank, determinism, shipped == regenerated, world structure (298 clubs, 3 tiers, every club in one division, relations/kits valid), squads (28, balanced, valid, nationality mix, strength ladder), name uniqueness against the whole world, youth, crests, and one full simulated season with promotion and relegation (28 s for 15 divisions).
