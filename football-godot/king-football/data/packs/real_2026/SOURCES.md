# Sources of this data pack (season 2026-27)

- Divisions, squads, shirt numbers, nationality, date of birth, height, positions, managers, stadiums:
  English Wikipedia (CC BY-SA 4.0): each club's "Current squad" table and each player's article.
  Every club file records the article revision it was built from (`squad_source`).
- LaLiga club list cross-checked with openfootball (CC0).
- Preferred foot, detailed position, market value, contract end: transfermarkt-datasets, snapshot 2026-07-06.
- Ratings: ESTIMATES (see docs/REAL_DATA_PACK_2026.md).
- No club badges, kit artwork or player photos are included.
